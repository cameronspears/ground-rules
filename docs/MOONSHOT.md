# Moonshot: tiny and smooth

The goal: Ground Rules loads in a blink, fits in a phone's memory and never stutters, and plays exactly as before.

## Targets

| | Target | Before |
|---|---|---|
| Download to start playing | under 500 KB zipped | 416 KB of code; then 4 MB of sound fetched on the first click |
| Picture memory, 4-side Wild West game | under 150 MB | 503 MB in 10,069 pictures |
| Frame rate in the biggest battles | a steady 60 | to measure |
| Load to playable, warm cache | under 2 s | 6.5 s on the dev server |
| Long frames from baking mid-game | none | to measure |

Hard rule: pinned simulator matches keep identical fingerprints, and every baked picture stays pixel-identical. Anything that changes how the game looks or sounds is the owner's call.
